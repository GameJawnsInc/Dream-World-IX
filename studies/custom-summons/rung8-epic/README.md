## 2. The lanes

Five independent build lanes compose into one cast, matching STORYBOARD §1/§4/§5/§6:

1. **Creature** (`creature/`) — mesh + rig + atlas + 3 clips, 100% authored, zero donor.
2. **Particles** (`nimbra.seq`'s siblings: `MistFloor.sfxmodel` / `MistWisps.sfxmodel` /
   `RiftFlash.sfxmodel`) — three original sprite `.sfxmodel` files, the rung-5 idiom.
3. **Audio** (`audio/`) — three synthesized-in-Python `.ogg` cues, minted sfx ids 100001-100003.
4. **Sequence** (`nimbra.seq`) — the hand-authored `PlayerSequence.seq`, no donor, no splice, no stock
   `.seq` read at all — linted by `summons/seqlint.py` (K5, the silent-skip guard).
5. **Wiring** (`nimbra.summon.toml` + `bench/rung8.field.toml`) — the `[[summon]]` block (K1-K4: an
   authored `sequence=`, authored `clips=[...]`, authored `particles=[...]`, and a `[summon.staging]`
   curve table) plus the `"Nimbra"` ability on Iviv's Spark command.

## 3. The stage layout

`stage/` is the offline rehearsal tree `build_rung8_stage.py` / `bench/build_rung8_bench.py` write to —
never the live game install:

- `stage/FF9CustomMap/…` — what the lane-level `build_rung8_stage.py` emits (summon-deploy's own output,
  step 2 only).
- `stage/audio/` — the audio lane's own staged `.ogg` + manifest fragment (step 3 only).
- `stage/creature/` — the creature lane's staged `.anim` clips, read by the sequence-lane emitter.
- `stage/final/` — **the full three-step rehearsal** `bench/build_rung8_bench.py --clean --check` builds
  (field + summon + audio together) and the 49-point `BENCH-REPORT.json` it grades itself against.
- `stage/.summon-backups/`, `stage/.summon-revert/`, `stage/final/.summon-revert/` — the ledger's
  per-deploy backups and the auto-generated, stdlib-only revert scripts (the
  `tools/deploy_field.py` revert convention, scoped to a summon deploy).

None of `stage/` is committed; it is regenerated by re-running the build scripts (RUNBOOK §3's
"rehearse any step first" commands).

## THE TWO DEVIATIONS

*(cited by `nimbra.summon.toml`'s header comment)* — the full write-up, with the forcing reason for
each, lives in [`SEQUENCE-LANE.md` §2](SEQUENCE-LANE.md#2-the-two-deviations-both-forced-both-flagged).
In one line each:

1. **`[summon.staging]` is a TABLE, not a string *and* a table.** STORYBOARD §6.4's example TOML writes
   both `staging = "curves"` and a `[summon.staging]` table — not expressible in TOML. The table's
   presence is now what selects curves mode; every key/value/number is otherwise exactly as specified.
2. **The P5 `MistWisps` spawn moves before `WaitSFXDone`, not after.** STORYBOARD Appendix A's *draft*
   sequence text lists it after `WaitSFXDone` (which resolves at t = 480); §4.2's own prose pins the
   spawn at t = 405. `nimbra.seq` follows §4.2 — a one-line, zero-tick reordering (`CreateVisualEffect`
   is fire-and-forget). **Superseded by the retime**: the dissolve spawn now sits at **t = 113**,
   inside P4, on the tick the Scaling dissolve is already running (STORYBOARD §11.1/§11.3).
