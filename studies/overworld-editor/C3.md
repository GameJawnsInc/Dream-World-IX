# C3: the recipe is the document

**Status:** built 2026-10-23; the acceptance holds on the real island (`c3_lab.py`) and in the tests. Owner request:
"keep pushing forward with the plan".

## What it does

A **Recipe** bar sits above the carry cards in the World tab's 3D view, for the folder's one draft (both tools
write it):

- **Every Accept is one recipe row**, the `[[forest]]` / `[[mountain]]` table `world-fuse` composes with the same
  verb call. `world.recipe.row_for` builds the row from the very command the tool ran, parsed by the CLI's own
  parser, so the row cannot say anything the command did not.
- **Undo / Redo** walk the rows byte for byte. Each step snapshots every file at the cells it may write, before and
  after (`world.draft.begin_step` / `commit_step`; the dry run's own blocks for an Accept, the read window for a
  recipe row, the whole map for a row of any other table), and keeps only the cells that changed. An undo
  restores the before-images, a redo the after-images: no verb re-runs (0.2 s). An edit after an undo drops the
  undone steps. Undo refuses a step whose files moved since, and a step already promoted (Revert promote first;
  `promote` / `revert` set and lift that mark).
- **Save recipe…** writes the applied rows as TOML for `world-fuse`, each with `step = N`.
- **Open recipe…** composes a recipe into a fresh draft of the folder (after a confirm when the draft has edits),
  **one `world-fuse` job per row**, so every row is its own undoable step. A row that refuses stops the open there,
  keeping the rows before it, and says which row and why.

## THE ORDER LAW (`step`)

TOML keeps one array per table, and `world-fuse` ran a tier's tables in a fixed order (all mountains, then all
forests). An editor session that placed a forest and then a mountain beside it would re-compose in the other order,
and two shapes whose read windows overlap can carve different bytes in a different order. So a row may carry
`step = N`: inside a tier, stepped rows run first in step order, then the rest as before
(`fuse.ordered_rows`, which `compose_layout` now runs its rows through). A recipe without steps composes exactly as
it always did (the compose tests pass unchanged, bar one pinned tuple that gained `sink`).

## `[[sink]]`

A `world-fuse` row now runs `world-sink`'s own call (`at`, `cluster`, `allow_entrances`, `fresh`), with the CLI's
disc-4 replay: where disc 4's blocks differ, the same sink runs again on disc 4 with `skip_mirror=REPLAY`. It is in
the base tier (it sinks real land; relief rows read the deployed result). Proven against the CLI with a recording
stub (the same calls, the same keyword arguments, the replay included), not in game.

## The acceptance

- **Hermetic** (`tests/test_worldrecipe.py`): through the World tab, a forest, then a mountain turned 30° and ×1.5
  tall, the mountain undone and redone, the recipe saved; `world-fuse` on a copy of the folder writes the draft's
  world files byte for byte; the recipe opened again composes the same draft with one step per row, and undoing
  both returns to the folder. A row that refuses stops the open and keeps the row before it.
- **On the real island** (`c3_lab.py`, real tools, real subprocess jobs, FF9CustomMap-world):
  - forest-grove at (1400, -460), then Uaho at (32, -528) turned 45° and ×1.3, into a fresh draft;
  - **R1:** `world-fuse <saved recipe>` onto a second fresh draft is **byte-identical over 1,531 world files**;
  - **R2:** Open recipe gives the same bytes, as two steps (forest-grove, then uaho);
  - **R3:** undoing both leaves the draft with no edits, equal to the folder.
  - Timings: undo 0.2 s; the 2-row compose 23.5 s; Open recipe 35.2 s (two jobs).

Records: `evidence/c3/c3_result.json`, `evidence/c3/saved-recipe.toml`.

## Found on the way

- **The preview missed open sea inside a deployed block.** A deployed block holds only its land, so a rim over its
  sea met no tris and passed the band law, and the carve then refused: "no plain-grass ground around the rim to
  anchor against". That anchor is now the preview's fourth law (the carve's own next refusal, the same gate), and
  the fence samples a sea hole; dropping the law turns it red.
- Two of FF9CustomMap-world's islands refuse every mountain with "kept grass ... has two float positions" (a weld
  in their own grass, not the carve's); the editor shows it as the carve's refusal.
